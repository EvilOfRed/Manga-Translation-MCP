
# 核查步骤

## 1. 通读全文，理解剧情与人物关系
- 阅读所有页面，把握故事脉络。
- 识别主要角色及其称呼，注意对话的发起者和接收者。

## 2. 消除“暂译”标注
- 对标注了「暂译」的人名、专有名词，根据上下文（包括后续页面的称呼、角色互动）确定最终译名。
- 原则：
  - 优先采用音译，并选择最符合中文习惯的汉字写法。
  - 若上下文中出现该角色的其他称呼或姓氏，应保持一致。
  - 若无更多信息，可参考日语常见姓氏音译，但需确保全篇统一。

## 3. 检查翻译准确性
- 逐句对照原文与译文，确认语义忠实、逻辑通顺、无漏译或增译、人称指代错误。
- 若有明显错误（如语法、用词不当），予以修正。
