# 任务处明

按照要求处理我即将提交的数据，并调用`append_json_file`工具将结果保存到：{{output_path}}

## 1. 任务概述
给定两份 JSON 数据：
- **数据 A（翻译数据）**：包含单页的对话片段，每条记录包含 `original`（原文）和 `translation`（译文）。
- **数据 B（OCR 识别数据）**：包含单页的文本检测框，每个框包含 `coords`（矩形坐标）和 `text`（OCR 识别出的文本）以及`label`(边界框标签，分为text_bubble和text_free两种)。

任务目标：
- 将数据 B 中的每个 `text` 与数据 A 中的 `original` 进行模糊匹配。
- 若匹配成功，则将对应的 `coords` 信息和`label`追加到数据 A 中相应的 `context` 条目中（新增 `boxes` 字段）。
- 一个 `original` 可能匹配到多个 `text`（例如短语被拆分为多个 OCR 框）,需将所有coords以及label追加到`boxes`中。


## 2. 匹配细则

- 如果某个text没有匹配到任何original，则忽略。

- 若一个 OCR `text` 匹配了多个 `original`，将`coords`分配给最匹配的`original`，保证一个`coords`只分配一次，允许`original`无`coords`

- **多个 OCR 文本拼起来近似于一个 original**:`text`被认为时`original`的字串时，避免将本该分散到不同box的内容聚拢到一起，把 original / translation 拆成多条，各自挂自己的 coords + label。
  - **拆分示例**：
  ```json
  数据 A：
  {
    "original": "你好世界",
    "translation": "Hello world",
    "layout":"vertical"
  }
  数据 B：
  {
    "label": "text_bubble",
    "coords": [
      848.618408203125,
      2755.61083984375,
      1053.561279296875,
      3235.62158203125
    ],
    "text": "你好",
    "layout":"vertical"
  },
  {
    "label": "text_bubble",
    "coords": [
      464.7469482421875,
      2789.230712890625,
      618.1741333007812,
      3408.11572265625
    ],
    "text": "世界",
    "layout":"vertical"
  }
  数据A拆分后添加`box`信息：
    {
      "original": "你好",
      "translation": "Hello",
      "boxes": [
        { "coords": [848.618408203125,2755.61083984375,1053.561279296875,3235.62158203125], "label": "text_bubble" }
      ],
      "layout":"vertical"
    },
    {
      "original": "世界",
      "translation": "world",
      "boxes": [
        { "coords": [464.7469482421875, 2789.230712890625, 618.1741333007812, 3408.11572265625], "label": "text_bubble" }
      ],
      "layout":"vertical"
    },

  ```

- **重复原文处理**：若同一页内存在多个内容完全相同的`original` 条目，默认追加所有coords到第一个`original`中




## 3. 输出数据格式

```json
[
  {
    "page": "1",
    "context": [
      {
        "original": "...",
        "translation": "...",
        "boxes": [
          { "coords": [.., .., .., ..], "label": "text_bubble" },
          { "coords": [.., .., .., ..], "label": "text_free" }
        ],
        "layout":"horizontal"
      },
      {
        "original": "...",
        "translation": "...",
        "boxes": [
          { "coords": [.., .., .., ..], "label": "text_bubble" }
        ],
        "layout":"horizontal"
      },
      {
        "original": "...",
        "translation": "...",
        "boxes": [],
        "layout":"vertical"
      }
    ]
  }
]

```

## 字段说明：

coords：数组，包含四个整数，分别表示检测框的 左上角 x、左上角 y、右下角 x、右下角 y（或根据原始数据定义，通常为矩形边界）。

label：字符串，取值为 "text_bubble" 或 "text_free"，表示该检测框的类别标签，直接取自数据 B 中对应 coords 的 label 字段。
