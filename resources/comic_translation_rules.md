# 漫画翻译准则

---

## 1. 翻译原则
- **忠实传达原意**：不得增删、扭曲或模糊源文本的语义、逻辑与事实信息。
- 保留原文的修辞、反问、讽刺、幽默等意图，若目标语无法直译，需用等效手法再现。
- 译文须符合目标语的**语法规范**与**表达习惯**，避免“翻译腔”。

---

## 2. 特殊要求

- **对不确定的内容**：在信息不全时，对未明确交代的人名、称呼、专有名词等，仅做字面直译或音译，并加“暂译”注释，严禁尝试补全或推测其完整含义，所有解释权交由后续页面。

- **记录文字的排列方式**：将文字的排列信息存入`layout` 字段。

---

## 3. 拟声词处理规则
- **默认忽略**：出现在分镜框外、背景插图、封面彩页中，用于渲染气氛、表现动作音效（如身体晃动、布料摩擦、风声、引擎声、脚步声等）的拟声词，一律不翻译、不录入JSON。
- **例外（必须翻译）**：仅当拟声词位于对话框/气泡内部，或作为标题/显著大字构成实质性文本内容时，才作为正常条目翻译录入。


---

## 4. 输出格式
- 最外层为一个对象，包含 page（页码）和 context（内容数组）两个键。
- 每个条目包含 `original` 、`translation`、`layout` 字段。
 - **字段说明**：
  - `original`：原文。
  - `translation`：译文。
  - `layout`：文字排本只允许两个取值:"horizontal"、"vertical"。



## 5. 输出示例
```json
{
  "page": 1,
  "context": [
    {
         "original": "...(省略)", 
         "translation": "...(省略)",
         "layout":"horizontal"
    },
    {
         "original": "...(省略)", 
         "translation": "...(省略)",
         "layout":"vertical"
    }
  ]
}
```
